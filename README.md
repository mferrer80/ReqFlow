# ReqFlow
ReqFlow IA centraliza solicitudes de soporte, errores y mejoras de distintos proyectos. Utiliza inteligencia artificial para interpretar mensajes y capturas, detectar información faltante y proponer incidencias sujetas a revisión humana. Incluye seguimiento, generación de prompts para Codex o creación de una tarea en JIRA y reportes mensuales de actividades.
